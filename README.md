# Apex AI Trader Dashboard

Pure client-side React dashboard for Vercel deployment.

## Features
- Live market price fetch from public APIs
- Manual analysis mode for BTC, ETH, XAUUSD, EUR/USD
- Timeframe selector: 1m, 5m, 15m, 30m, 1h, 4h
- Advanced signal generation using RSI, EMA, MACD, Bollinger Bands, and Price Action
- Client-side chart and alert panel

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
